#  Ração de Canto — Resgatando Vidas

Projeto web desenvolvido para apresentar o **Ração de Canto**, uma iniciativa voltada ao **resgate, cuidado e adoção de animais**.

A plataforma permite acompanhar animais resgatados, conhecer a equipe responsável e descobrir formas de ajudar a causa.

---

# 📖 Descrição

O **Ração de Canto** é um website institucional que tem como objetivo divulgar o trabalho de resgate animal, facilitar o contato com apoiadores e incentivar adoções responsáveis.

A aplicação foi desenvolvida com foco em:

- **Apresentação de animais resgatados**
- **Divulgação da equipe responsável**
- **Conscientização sobre adoção e proteção animal**
- **Facilidade para pessoas interessadas em ajudar ou adotar**

### Problema que o projeto resolve

Organizações e iniciativas de resgate animal muitas vezes não possuem uma plataforma digital estruturada para divulgar seu trabalho.  
Este projeto oferece uma solução simples e acessível para:

- Mostrar animais disponíveis para adoção
- Organizar informações sobre resgates
- Engajar apoiadores da causa

### Público-alvo

- ONGs de proteção animal
- Projetos independentes de resgate
- Pessoas interessadas em adoção responsável
- Voluntários e apoiadores

#  Funcionalidades

Principais recursos do sistema:

-  **Apresentação de animais resgatados**
-  **Filtros por espécie e status**
-  **Seção de equipe**
-  **Menu responsivo para dispositivos móveis**
-  **Lightbox para visualização de imagens**
-  **Contadores animados**
-  **Formulário de contato**
-  **Boas práticas de segurança no JavaScript**

### Destaques técnicos

- Validação de dados via **whitelist**
- Proteções contra **injeção de URLs**
- Controle de eventos para evitar **spam no formulário**
- Uso de **Content Security Policy (CSP)** no HTML
